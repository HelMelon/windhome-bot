# telegrambot — квартиры и заброшки в Telegram

Бот с двумя режимами поиска недвижимости по Беларуси:

- **«Квартиры»** — тянет объявления с Kufar (Гомельская область, продажа) через их
  search-API и присылает карточки: адрес, площадь, жилая, балкон, этаж, цена, ссылка
  и геолокация объекта на карте.
- **«Заброшки»** — ищет объекты в реестре заброшенных домов
  [ЕРИС](https://eri2.nca.by/guest/abandonedObject/): тип объекта, статус, дата осмотра,
  площадь, стоимость и альбом фотографий.

## Стек

Python, [aiogram 3](https://aiogram.dev), aiohttp, ujson.

## Запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=<токен от @BotFather>
python hello.py
```

Токен читается из переменной окружения `BOT_TOKEN` — в репозиторий его не коммитим.

> ЕРИС отдаёт 429 при частых запросах и вращает выдачу, поэтому бот ходит в реестр
> только по нажатию кнопки, а не по таймеру.
