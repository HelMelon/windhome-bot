# Windhome — слежение за объявлениями (Kufar / Realt / ЕРИС) с доставкой в Telegram

Бот-монитор объявлений: не «нажми кнопку — получи всё», а «проверяю каждые
20 минут и присылаю только новые». Первая версия была кнопочным ботом на aiogram,
искавшим квартиры в Гомеле; эта — переписана в монитор с дедупликацией и
настраиваемым фильтром.

## Что делает

| Источник | Откуда данные | Фильтры |
|---|---|---|
| `kufar` | `api.kufar.by/search-api/v2/search/rendered-paginated` | в запросе: цена, площадь, комнаты |
| `realt` | HTML-страница, JSON из `<script id="__NEXT_DATA__">` | на нашей стороне: город, площадь, цена (USD→BYN по курсу НБРБ) |
| `eri2` | `eri2.nca.by/api/guest/abandonedObject/...` | регион (по умолчанию весь РБ) |

Уведомление приходит один раз на объект: дедупликация по `(source, uid)` в
SQLite. Первый обход на чистой базе ничего не рассылает — существующая
выдача просто запоминается, иначе чат получает лавину сообщений.

## Команды бота (@HomelessYetBot)

- Кнопки «🏠 Куфар», «🏡 Realt», «🏚 Заброшки» — полная выдача под текущий фильтр.
- Команды для групп: `/kufar`, `/realt`, `/zabroshki` (кнопки-тексты в группе
  видны только при выключенном privacy mode, команды — всегда).
- `/status` — фильтр, размер базы, время последней проверки, ошибки источников.
- `/check` — принудительный обход (без рассылки уведомлений).
- `/pause`, `/resume` — выключить/включить уведомления.
- `/id` — chat_id (нужен, чтобы добавить получателя).
- `/allow` — добавить текущий чат (группу) в получатели; только владелец
  (в личке это её собственный chat_id из конфига). `/forget` — убрать.

### Фильтр из чата

`/filter` (или кнопка «⚙️ Фильтр») присылает панель с кнопками: площадь (50–100+),
цена (150–350k), комнаты (1 / 2 / 3 / 3–4 / любые), районы Гомеля и «любой»,
плюс «♻️ Сбросить» и «🔄 Пересчитать». Текущее значение помечено ✓, панель
перерисовывается на месте, а внизу сразу считается: **«Под фильтр сейчас: N
(Kufar: x, Realt: y)»** — с кнопкой «👀 Показать N». Если совпадений ноль, панель
так и пишет и предлагает ослабить условия. То же самое руками — командами ниже.

Правки ложатся поверх `config.json` и живут в SQLite, файл на сервере трогать
не нужно:

| Команда | Что делает |
|---|---|
| `/filter площадь 60` | минимальная общая площадь, м² |
| `/filter цена 300000` | потолок цены в BYN (пробелы и «до» не мешают) |
| `/filter комнаты 3,4` | список комнат; `любые` — без ограничения |
| `/filter район Центральный` | район города; несколько — через запятую |
| `/filter город Гомель` | город (Realt фильтруется по нему) |
| `/filter регион Гомельская` | для ЕРИС, `любой` = все области |
| `/filter reset` | вернуть значения из `config.json` |

После смены фильтра ближайший цикл монитора принимает текущую выдачу **молча**
(маркер `filter_version`), иначе расширение фильтра дало бы лавину «новых»
старых объявлений. Посмотреть, что подходит прямо сейчас — кнопка или `/check`.

### Работа в группе

1. Добавить бота в группу, написать там `/allow` — чат попадёт в `extra_chats`
   в SQLite, и уведомления пойдут уже и в группу.
2. Чтобы бот видел обычный текст (кнопки «Куфар» и т.п.), в @BotFather нужно
   `/setprivacy` → выбрать бота → **Disable**, после чего **удалить и снова
   добавить бота в группу** — иначе Telegram отдаёт боту только команды и
   упоминания. С командами `/kufar` и т.д. privacy mode можно не трогать.
3. Права администратора боту не нужны.

## Настройки — `config.json` (правится без остановки сервиса)

```json
"filter": { "city": "Гомель", "area_min": 80, "price_max_byn": 250000, "rooms": [3] }
```

- `area_min` — минимальная общая площадь, м².
- `price_max_byn` — потолок цены в BYN (Kufar — копейки в API, Realt — пересчёт).
- `rooms` — список комнат; `[]` — без ограничения.
- `region_contains` — для ЕРИС: `""` = все области, `"Гомельская обл"` = только она.
- `districts` — районы города. Ни Kufar, ни Realt район не отдают, поэтому он
  считается по координатам: полигоны районов Гомеля тянутся из OSM через
  Nominatim (`polygon_geojson=1`, 4 запроса), кэшируются в SQLite на месяц, и
  дальше точка проверяется локально (ray casting, без зависимостей). Если у
  объявления нет координат — район считается неизвестным и объявление **не
  отбрасывается** (лучше лишнее, чем пропущенное). Обновить полигоны досрочно:
  `sqlite3 data/windhome.db "delete from kv where key like 'districts:%'"` и
  рестарт.
- `poll_interval_min`, `notify_limit`, `chat_ids`, `sources.{kufar,realt,eri2}`.
- `interval_min` у каждого источника — своя частота. Kufar и Realt опрашиваются
  каждые 20 минут. ЕРИС: `interval_min: 0` + `notify: false` — только по кнопке
  «🏚 Заброшки». Причины: его API отдаёт `429 Rate limit exceeded` (лимит по IP,
  жёсткий), а выдача поиска — «вращающаяся» страница из 10 объектов, поэтому
  фоновый пуш превратился бы в поток не-новых объектов.

Конфиг перечитывается на каждом цикле монитора и в каждом handler'е, поэтому
`systemctl restart` для смены фильтра не нужен.

## Что важно знать

- **Kufar с фильтром «≥80 м² + ≤250 000 BYN + 3 комнаты» сейчас отдаёт 0
  объявлений** — это состояние рынка в Гомеле, а не поломка. В Гомеле всего
  9 квартир от 80 м², и все дороже 300 000 BYN.
- Realt отдаёт цены в USD/EUR/BYN; конвертация — по официальному курсу НБРБ
  (`api.nbrb.by`), кэш на 6 часов, при недоступности — `fallback_usd_byn`.
- Старый бот звал `/_next/data/<buildId>/...json` — этот путь умирает при
  каждом деплое Realt (уже отдаёт 404). Здесь buildId не нужен.
- ЕРИС отвечает 429 на частые запросы: детали объекта (`/forView`) тянутся
  только для новых объектов, по одному, с паузой `detail_delay_s`.
- Ссылка ЕРИС ведёт на JSON-карточку API: человекочитаемой страницы у
  объекта нет.

## Файлы

```
main.py          вход: бот + фоновый монитор в одном процессе
config.py        чтение config.json, токен из окружения
bot.py           aiogram: кнопки, команды, доступ по chat_ids
monitor.py       цикл обхода, дедупликация, рассылка
sources/         kufar.py, realt.py, eri2.py, __init__.py (fan-out)
render.py        формат сообщения
store.py         SQLite: seen + kv
rates.py         курсы НБРБ
net.py           aiohttp-сессия с браузерным User-Agent
selftest.py      обход источников без Telegram (диагностика)
send_probe.py    проверка доставки в чат
```

## Установка / обновление

```bash
# локально
cp config.example.json config.json      # вписать свой chat_id и фильтры
pip install -r requirements.txt
python selftest.py                      # проверка источников без Telegram
WINDHOME_TOKEN=<токен> python main.py
```

```bash
# на сервере
/opt/windhome/venv/bin/pip install -r /opt/windhome/requirements.txt
systemctl restart windhome
journalctl -u windhome -n 30 --no-pager
```

Токен — в `/opt/windhome/.env` (`WINDHOME_TOKEN=...`, chmod 600), в git не попадает.

Диагностика без Telegram:

```bash
cd /opt/windhome && set -a && . ./.env && set +a && venv/bin/python selftest.py
```
